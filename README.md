# OSINT Mobile

OSINT-инструмент для Android: Deep IP, Phone HLR, VK OSINT, CCTV Cameras, Ship Tracker.

## Сборка APK
1. Открой вкладку **Actions**
2. Выбери workflow **Build OSINT APK** -> **Run workflow**
3. Жди ~30-40 минут
4. В конце заходи в запущенный прогон -> раздел **Artifacts** -> скачай **OSINT-apk**
5. Перекинь .apk на телефон и установи
